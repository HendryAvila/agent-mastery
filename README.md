# Agent Mastery: De Usuario a Arquitecto de Agentes IA

> Curso interactivo para dominar agentes IA: desde entender que son hasta disenar arquitecturas multi-agente en produccion.

## Sobre este proyecto

Este curso interactivo fue **orquestado por [Hendry Avila](https://github.com/hendryavila)** y **generado con asistencia de Inteligencia Artificial**.

### Filosofia

Este proyecto es **Open Source** y su unico proposito es **la educacion**. Nace de la conviccion de que el aprendizaje debe ser:

- **Accesible**: Gratis, abierto, y disponible para todos
- **Dinamico**: Interactivo, no solo texto estatico
- **Adaptable**: Cada persona aprende a su ritmo
- **Practico**: Aprender haciendo, no solo leyendo

### Nota sobre la implementacion tecnica

El desarrollo tecnico de este curso (codigo, estructura, patrones) puede o no seguir las mejores practicas de ingenieria de software. **Ese NO es el foco del proyecto.** El objetivo es proveer un espacio de aprendizaje diferente, dinamico y efectivo. Si encuentras mejoras tecnicas, los PRs son bienvenidos.

## Que vas a aprender

- Que es un agente IA y como funciona internamente (LLM + Tools + Memory + Planning)
- Tool calling y function calling: el corazon tecnico de todo agente
- El ecosistema completo de agentes 2026: Claude Code, OpenCode, Cursor, Roo Code, y mas
- Mejores practicas para trabajar CON agentes (system prompts, MCP, flujos de trabajo)
- Como construir tu propio agente desde cero
- Sistemas de memoria y estrategias de razonamiento (CoT, ToT, ReAct)
- Frameworks multi-agente: Claude SDK, OpenAI SDK, Strands, CrewAI, LangGraph
- Patrones de orquestacion: Orchestrator-Worker, Handoff, Hierarchical, Pipeline
- Guardrails, seguridad, y evaluacion de agentes
- El entorno profesional: terminales, IDEs, Agent Teams
- Agentes en produccion: observabilidad, costos, CI/CD
- Diseno de arquitecturas multi-agente completas

## Tech Stack

- [SvelteKit 5](https://svelte.dev/) — Framework web
- [Tailwind CSS v4](https://tailwindcss.com/) — Estilos
- [Static Adapter](https://kit.svelte.dev/docs/adapter-static) — Deploy estatico
- GitHub Pages — Hosting

## Como ejecutar localmente

```bash
git clone https://github.com/hendryavila/agent-mastery.git
cd agent-mastery
npm install
npm run dev
```

Abre `http://localhost:5173` en tu navegador.
